The simplest way to manage ads on your WordPress site with powerful URL and device targeting.

== Description ==

**SmartSpot Ad Manager Pro** makes it incredibly easy to display ads anywhere on your WordPress website. Whether you're using Google AdSense, custom HTML ads, or banner images, this plugin gives you complete control without the complexity.

### Why SmartSpot Ad Manager Pro?

* **Easy to Use** - Intuitive interface that anyone can master in minutes
* **Powerful Targeting** - Show ads on specific URLs, devices, and positions
* **No Bloat** - Clean, lightweight code that won't slow down your site
* **Flexible** - Support for images, AdSense, and custom HTML/JavaScript
* **Developer Friendly** - Well-documented with shortcodes, widgets, and template functions

### Key Features

✅ **URL Targeting** - Display ads on specific pages using exact match, contains, or starts with patterns
✅ **Device Targeting** - Show different ads on desktop, mobile, or tablet devices
✅ **Multiple Ad Types** - Image ads with links or custom code (AdSense, HTML, JavaScript)
✅ **Priority System** - Control which ads display first when multiple ads match
✅ **Unlimited Positions** - Header, footer, sidebar, before/after content, or custom positions
✅ **Simple Interface** - No complicated settings or confusing options
✅ **Shortcode Support** - Place ads anywhere with `[thesiadm_ads position="header"]`
✅ **Widget Ready** - Add ads to any widget area
✅ **Template Functions** - For developers: `thesiadm_display_ads('position')`

### Perfect For

* Bloggers monetizing with AdSense
* Publishers managing banner ads
* Affiliates promoting products
* Businesses advertising services
* Developers building client sites

### How It Works

1. **Create an Ad** - Upload an image or paste your ad code
2. **Set Target URLs** - Specify which pages should show the ad
3. **Choose Devices** - Select desktop, mobile, tablet, or all
4. **Pick a Position** - Where the ad should appear
5. **Publish** - Your ad is live!

### Display Methods

**Shortcode:**
`[thesiadm_ads position="header"]`

**Widget:**
Add the "SmartSpot Ad Manager" widget to any sidebar

**Template Function:**
`<?php thesiadm_display_ads('before-content'); ?>`

### Available Positions

* Header
* Before Content
* After Content
* Sidebar
* Footer
* Custom Position 1
* Custom Position 2

### URL Targeting Examples

**Exact Match:**
`/about-us/` - Only shows on the About Us page

**Contains:**
`/blog/` - Shows on /blog/, /blog/post-1/, /my-blog/, etc.

**Starts With:**
`/products/` - Shows on /products/, /products/shoes/, /products/electronics/gaming/, etc.

### Device Targeting

Select which devices should see each ad:
* 🖥️ Desktop
* 📱 Mobile
* 📱 Tablet

Perfect for showing different ad sizes or formats based on screen size.
